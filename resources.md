# Resources

## Agent skills & plugins

- [animate](https://github.com/cth9191/animate): Short clip in a single canvas file, storyboarded as it goes. — #canvas #claude-skills #motion-design #skill #storyboard #video
- [claude-motion](https://github.com/whaleyxbt/claude-motion): Motion skill with taste; checks its own frames, writes sound in code. Built for Opus 5.5. — #audio #claude-skills #motion-design #skill #video
- [claude-motion-design](https://github.com/howseen-ai/claude-motion-design): Motion design via HTML, Playwright and ffmpeg — no Remotion. — #claude-skills #ffmpeg #html #motion-design #playwright #skill #video
- [claude-remotion-skill](https://github.com/haidrrrry/claude-remotion-skill): A Remotion editor from one prompt: captions, B-roll, sound. — #b-roll #captions #claude-skills #motion-design #remotion #skill #video
- [hyperframes-motion-reel-skill](https://github.com/Sunwood-ai-labs/hyperframes-motion-reel-skill): Showreel cut to the beat at 120 BPM, built on HyperFrames. — #claude-skills #hyperframes #motion-design #music-sync #skill #video
- [hyperframes-student-kit](https://github.com/nateherkai/hyperframes-student-kit): 14 skills and 406 motion graphics reference cards for HyperFrames. — #claude-skills #hyperframes #motion-design #reference #skill #video
- [klik-anim-skill-creation](https://github.com/t3knobox/klik-anim-skill-creation): Skill encoding the laws of animation and camera movement. — #animation-principles #camera #claude-skills #motion-design #skill #video
- [motion-design-skill (LottieFiles)](https://github.com/LottieFiles/motion-design-skill): Engine-agnostic motion principles skill. — #animation-principles #claude-skills #lottie #motion-design #skill #video
- [motion-design-skills](https://github.com/iart-ai/motion-design-skills): Skills for timing, color, typography, logos; Remotion-based. — #claude-skills #motion-design #remotion #skill #typography #video
- [motion-dev-animations-skill](https://github.com/199-biotechnologies/motion-dev-animations-skill): Web UI animation with Motion.dev (not video). — #claude-skills #motion-design #motion-dev #skill #video #web-animation
- [motion-graphics](https://github.com/Barty-Bart/motion-graphics): Generates B-roll straight from a transcript. — #b-roll #claude-skills #motion-design #skill #transcript #video
- [motion-graphics-skills](https://github.com/charlie947/motion-graphics-skills): 13 skills for making launch videos. — #claude-skills #launch-video #motion-design #skill #video
- [product-launch-motion](https://github.com/AbubakrChan/product-launch-motion): Full product launch film: voice-over, camera, color grade. — #claude-skills #launch-video #motion-design #skill #video #voice-over

## Media, video & animation engines

- [GSAP](https://github.com/greensock/GSAP): JavaScript animation timelines; what HyperFrames runs on. Skills: npx skills add greensock/gsap-skills — #claude-skills #engine #gsap #javascript #motion-design #video
- [HyperFrames](https://github.com/heygen-com/hyperframes): Render engine: HTML to MP4. The most commonly installed engine for these skills. — #claude-skills #engine #html #hyperframes #motion-design #video
- [lottie-web](https://github.com/airbnb/lottie-web): Render Lottie animations on the web — for when you need Lottie, not MP4. — #claude-skills #library #lottie #motion-design #video #web-animation
- [Remotion](https://github.com/remotion-dev/remotion): Render engine: programmatic video written in React. — #claude-skills #engine #motion-design #react #remotion #video
